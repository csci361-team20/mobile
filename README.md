# BiletFlow mobile

The Flutter application is in [`ticketapp`](ticketapp). It uses the same BiletFlow REST API as the web client.

The SRS mobile MVP is an online ticket-verification app for assigned event staff. The app provides assigned events, camera scanning, exact QR text entry, attendee search, admission results, counts, history, and authorized check-in reversal. Existing attendee, organizer, account, and support screens also use backend records.

See [`ticketapp/README.md`](ticketapp/README.md) for setup, API configuration, checks, builds, and the presentation walkthrough.
